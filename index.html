    1. Seleccionar elementos

    Nivel básico

    Antes de cambiar algo en la página, hay que encontrarlo. El objeto document representa toda la página y nos da métodos para buscar elementos.

    document.getElementById('titulo');        // por id → un elemento
document.querySelector('.parrafo');       // por selector CSS → el primero
document.querySelectorAll('.parrafo');    // por selector CSS → todos (lista)

    Soy el título con id="l1-titulo"

    Párrafo 1 (clase l1-parrafo)

    Párrafo 2 (clase l1-parrafo)

    Párrafo 3 (clase l1-parrafo)

    querySelector devuelve un elemento; querySelectorAll devuelve una lista (NodeList) que se recorre con forEach.

    2. Cambiar contenido y atributos

    Nivel básico

    Una vez seleccionado un elemento podemos modificar su texto, su HTML interno y sus atributos.

    elemento.textContent = 'Hola';          // texto plano (seguro)
elemento.innerHTML = '<b>Hola</b>';     // interpreta HTML
elemento.setAttribute('href', 'https://...');
elemento.getAttribute('href');
    (aquí aparecerá el resultado)

    Enlace: MDN Web Docs

    ⚠️ Usa textContent cuando muestres texto que escribió el usuario. innerHTML interpreta etiquetas y puede ser peligroso con datos no confiables.

    ✏️ Ejercicio

    Escribe en el campo <h1>Hola</h1> y compara lo que muestran textContent e innerHTML. ¿Por qué se ven distintos?

    3. Cambiar estilos y clases

    Nivel básico

    Podemos modificar el CSS de dos formas: directamente con style, o (mejor) agregando y quitando clases con classList.

    caja.style.backgroundColor = 'tomato';   // estilo en línea
caja.classList.add('activa');            // agregar clase
caja.classList.remove('activa');         // quitar clase
caja.classList.toggle('activa');         // alternar
    Soy una caja

    ✏️ Ejercicio

    4. Eventos

    Nivel básico → medio

    Un evento es algo que ocurre en la página (un clic, una tecla, enviar un formulario). Con addEventListener decimos qué función ejecutar cuando ocurra.

    boton.addEventListener('click', function (evento) {
  console.log('Me hicieron clic', evento);
});

formulario.addEventListener('submit', (e) => {
  e.preventDefault();   // evita que la página se recargue
});

    5. Crear y eliminar elementos

    Nivel medio

    El DOM no es estático: podemos crear elementos desde JavaScript, insertarlos en la página y quitarlos.

    const li = document.createElement('li');   // 1. crear
li.textContent = 'Nuevo elemento';         // 2. configurar
lista.appendChild(li);                     // 3. insertar al final
lista.prepend(li);                         //    o al inicio
li.remove();                               // eliminar

      6. Recorrer el DOM

      Nivel medio

      Los elementos forman un árbol. Desde uno podemos navegar a su padre, sus hijos y sus hermanos.

      elemento.parentElement;          // el padre
elemento.children;               // los hijos (elementos)
elemento.nextElementSibling;     // el hermano siguiente
elemento.previousElementSibling; // el hermano anterior
elemento.closest('.caja');       // el ancestro más cercano que coincida

      7. Delegación de eventos y localStorage

      Nivel medio

      Si la lista tiene muchos elementos (o se crean dinámicamente), no conviene poner un listener en cada uno. Ponemos uno solo en el padre y revisamos evento.target. Además guardamos los datos en el navegador con localStorage para que no se pierdan al recargar.

      // Delegación: un solo listener en la lista
lista.addEventListener('click', (e) => {
  if (e.target.matches('.borrar')) { /* ... */ }
});

// localStorage solo guarda texto → usamos JSON
localStorage.setItem('tareas', JSON.stringify(arreglo));
const guardadas = JSON.parse(localStorage.getItem('tareas')) || [];
